# HOLE: The Last Light 🎮

HOLE: The Last Light is a space-themed arcade game where the main goal is to collect glowing circles, earn points, and survive while avoiding dangerous red hazards. As the game progresses, the difficulty increases, making it more challenging to stay alive and achieve a high score.

I wanted to create a game that is simple to understand but still fun and challenging to play. The game features neon-style visuals, a scoring system, combos, power-ups, increasing difficulty, and sound effects. It also saves your highest score so you can try to beat your personal best.

This project helped me explore how browser games work using HTML, CSS, JavaScript, Canvas, and Web Audio. It combines game logic, visual design, and interactive elements into a playable experience that runs directly in a web browser without requiring any additional software.
